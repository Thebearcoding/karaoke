# 界面截图与素材说明

本目录保存点歌、搜索、待唱列表和字幕播放的六张实际截图，拍摄于隔离的本地演示环境。

## 字幕功能

粤语歌词带粤语拼音，日文歌词的汉字带平假名注音，显示在对应文字上方。读音在字幕视频准备阶段生成。全屏与正在播放截图展示陈奕迅《富士山下》的粤拼、当前句高亮和下一句预读。
