# 余音 · 网页卡拉 OK

## 运行

从工作区根目录启动：

```sh
.venv/bin/python -m karaoke.api
```

打开 <http://127.0.0.1:8746/>。网页与 API 由同一个服务提供，不需要 Node 构建或额外前端服务器。依赖沿用 [API.md](API.md)。

## 使用

1. 在点歌台搜索已有歌名／歌手，点击封面的 `＋` 加入歌单。标有「可以直接唱」的歌曲复用已生成文件。
2. 新歌粘贴 YouTube／Bilibili 单个视频链接，可填写歌名，点击「加入歌单」。仅有歌名时，可通过搜索结果区打开两个平台搜索并复制视频链接。
3. 点底部播放按钮，或歌单中的「现在唱」。首次点击会启用浏览器声音。
4. 已点歌曲可上移、下移、移除。调整顺序同时改变未开始的预处理优先级；当前处理和当前演唱继续进行。
5. 唱完自动进入下一首；若下一首尚未准备好则等待，可主动切歌跳过。加载完成才开始计算播放时间。

播放器有暂停、继续、拖动进度、重唱、全屏、音量及下一首。快捷键：空格暂停／继续，`N` 下一首，`F` 全屏；输入文字时不会触发。

### 三种声音模式

- **保留伴唱**：背景音乐＋伴唱，默认模式。
- **纯伴奏**：只放背景音乐。
- **原唱**：三条分离音轨合播，供跟唱和找旋律；它是 MP3 试听混音，不是 bitwise 母版。

三条音轨在一个 AudioContext 中同步调度，切换模式只调整增益，不重启歌曲。原始 float64 母版仍可通过 API 下载。字幕复用已经对齐、渲染好的 MV；这一版没有新增字幕算法，也没有接入 Codex。

### 遥控点歌

`/?remote=1` 使用同一歌单，可以点歌、排序和控制播放，但不发声。保持一个普通页面作为播放屏，其余设备使用遥控页面。

默认只监听本机。若明确需要同一局域网内的手机访问，可以启动：

```sh
KARAOKE_HOST=0.0.0.0 .venv/bin/python -m karaoke.api
```

手机访问 `http://电脑局域网IP:8746/?remote=1`。这是单房间应用，未实现账号和独立房间，局域网中可访问该地址的人都能操作同一歌单。

## 状态与恢复

- SQLite 保留歌单和任务，页面通过 SSE 接收更新与断线重连快照，不轮询。
- 正常关闭服务时暂停歌曲；重新打开网页可能需要点击启用声音。
- 移除歌单项不会删除媒体。已提交的预处理继续完成并留在曲库，失败项可以重试。
- 「首次准备」表示完整可播放文件尚不存在；历史实验的元数据、封面仍可以展示，但不会冒充现成伴奏。
- 自动歌词可能识别错误，网页会提示；预处理失败与正在等待会分别显示。
- 当前是本地单房间 MVP，浏览器内存保留当前歌曲的三条解码音轨。不是在线多人隔离服务，也暂不包含麦克风效果器、评分、升降调。
