# 余音点歌台

## 设计主张

像夜里一间安静的小唱片店：暗橄榄色背景、暖白文字、少量琥珀金。点歌是第一入口，歌单始终可见，切换到播放页后让 MV 占据主要位置。沿用已经选定的暖金跟唱字幕，不让网页装饰争夺注意力。通过封面、留白和文字层次建立气质，状态信息保持短小。

## 视觉系统

- 颜色：背景 `#111312`，表面 `#181b19`，正文 `#f2eee5`，次级文字 `#969d94`，金色 `#dfb56f`，就绪 `#a6c39b`。
- 字体：标题使用宋体／系统衬线，控件使用系统黑体；数字等宽。设计 token 在 `web/style.css` 的 `:root` 中。
- 布局：桌面为点歌／播放主区＋固定宽度歌单，底部常驻播放控制；手机通过导航切换三个主区。
- 动效：轻微悬停与准备状态指示，尊重减少动态效果偏好；播放器字幕继续使用已经对齐的 MV，不追加时间偏移。
- 可访问性：按钮有中文名称、键盘焦点、可见状态文字；图标按钮保留可访问名称。空格暂停、N 下一首、F 全屏，输入时不截获快捷键。

## 行为

一个共享房间，预处理队列与播放顺序分别维护。插队调整尚未开始的准备任务，不中断正在处理或播放的歌曲。下一首没有准备好时停留等待，可主动跳过。已点列表在服务端持久化；正常关闭服务时暂停播放。

进度通过 SSE 推送，初始连接及重连收到完整快照。处理进程通过标准输出事件汇报阶段，不定时读进度文件。客户端不会轮询状态。

准备进度放在歌曲状态位置：一行步骤名称与百分比，下面一条 3 px 暖金进度条。并行步骤各占一行，播放页复用同一种展示。没有可靠总量时用不定量进度条，不显示猜测的百分比；无需额外解释文案。渲染完成后的封装、校验仍显示各自状态，直到成品实际可用。

点歌后曲库立即出现该歌曲，语言分类随音频证据更新，不能把排队中的歌曲标为「已准备」。曲库、歌单与播放页共享 SSE 快照；只更新进度时保留按钮节点和键盘焦点，不重建整张卡片。

播放器使用一个 AudioContext 同时启动背景音乐、伴唱、主唱的三个解码音轨；MV 静音播放并跟随同一时钟。人声切换只调节增益，不重新载入视频。首次播放需要用户点击以启用浏览器声音。遥控模式控制同一房间但不发声。

加载歌曲时预载视频画面，并行解码三条音轨；全部可用后才允许启动播放时钟。升降调处理器在用户点击并启用声音后初始化，不阻塞首次加载，也不让「开始唱」按钮陷入等待点击的循环。

三个音轨滑杆在视频下方并排展示，名称、百分比和轨道对齐；手机改为三行。使用现有暖金色和等宽数字，不给声部引入额外颜色。全屏保留滑杆并为其留出空间，不盖住字幕。声音模式作为快捷预设，手动调整的数值跨歌曲保留。

全屏时把同一条播放进度条移到视频下方，显示已播和总时长，支持拖动；退出后移回底部控制栏。复用同一个控件及其播放时钟，避免全屏和普通视图各自维护进度。进度条占据独立空间，不覆盖歌词。

全屏控制区固定为紧凑的两行：第一行是完整进度条和时间，第二行是并排的三个小音量滑杆。此时收起预设、重唱按钮和解释文字；桌面控制区约 60 px 高，窄屏保留三列并让音量标签位于各自滑杆上方。

升降调使用画面右上角的小控件 `♭ 原调 ♯`，改变后中间显示有符号半音数，点击中间恢复原调。全屏保留同一个控件，不追加底部控制行，不在画面内放算法说明。
播放页去掉装饰英文和重复的模式说明。全屏只保留时间与三个声部名称，百分比仅在悬停或键盘调节时显示；滑杆始终提供可访问的名称与当前值。

页面文案只保留名称、操作和有用的状态。不要添加装饰英文、口号、缓存／预处理流程说明或重复的操作指引；空状态用短句，空间不足时才显示处理建议，歌词复核状态只用简短标签。

缓存用量放在歌单底部的折叠区，平时只展示已用／上限，展开后才显示容量设置和空间不足的处理提示。统计范围写入使用文档。缓存和音量变化都复用房间 SSE，不增加浏览器轮询。

文字点歌只展示有官方来源依据的真实搜索结果，每个视图最多 3 条，不凑数；正式翻唱、舞台演出不因不是原唱而被排除。无匹配时只显示「未找到官方版本」。封面点开预览，「加入歌单」和来源链接始终可见。输入停顿或回车触发，两站分别加载；不要在尚未完成搜索时显示「未找到」。全部结果优先显示 YouTube，B站排在其后，不按请求返回先后排序；YouTube 未返回时暂不在「全部」展示 B站，避免后续插入把用户正在点的按钮挤走。主动选择 B站可立即查看其结果，YouTube 失败或无结果时也可展示 B站。中文组词期间暂停请求，输入变化立即使旧结果失效。预览关闭即移除播放器，预览弹窗内不响应卡拉 OK 快捷键。搜索得到的视频标题仅作准备阶段的临时名称。

「下一首」使用文字加图标，在底部控制栏和画面左上角提供同一操作，全屏继续保留。不添加确认弹窗，不扩展底部两行控制区；请求期间禁用按钮，携带点击时的歌曲 ID 防止过期事件重复切歌。

搜索来源统一为「全部 / 本地 / YouTube / B站」。本地命中直接读取已有 SSE 曲库快照，与外部结果进入同一个列表；外部请求未完成或失败也保留本地结果。全部视图按本地、YouTube、B站排序并按视频 URL 去重，最多显示三条；各来源标签仍可查看自己的结果。本地已准备歌曲预览缓存 MV，加入歌单复用任务，不重新下载；搜索期间收起另一个曲库网格，避免重复展示。
