# 主唱／伴唱分离的评测口径

这是下一轮客观测试的建议协议，不是四首开发歌曲已经测得的成绩，也不新增未经校准的通过门槛。

## 有真实分轨时

参考声部为主唱 L、伴唱 H、背景音乐 I，输入为它们保持原时间轴、声道和相对电平的混合。主唱和伴唱的定义来自声部标注及必要的人工核对，不能只按性别、音高或唱的人数分类。

分开报告第二阶段模型在真实 `L + H` 上的分数，以及整条管线从 `L + H + I` 开始的分数；前者不能代表经过第一阶段分离误差后的最终效果。

| 指标 | 用途 | 局限 |
| --- | --- | --- |
| 每轨 SI-SDR | 总体波形重建质量，越高越好 | 忽略整体增益；不独立解释串音、缺失和伪影 |
| 每轨 SI-SIR | 目标相对于其他参考声部干扰的比例，越高越好 | 相关性极高的同音叠唱难以可靠归因；不能视作直接测量的残留百分比 |
| 固定增益重建分数 `10 log10(sum(s²) / sum((y−s)²))` | 在原音量下检查丢失、削弱及其他误差 | 对对齐和声部效果定义敏感；本项目明确公式，不与其他 SDR 定义混称 |
| SI-SAR（辅助） | 区分无法由参考声部解释的伪影 | 不是“金属音程度”或整体听感的直接测量 |
| 配对盲听 | 检查主唱／伴唱串音、完整度、失真及实际可唱性 | 少量用户试听记为初评，不当成正式 MOS |

SI 系列的定义参考 [Le Roux 等人的论文](https://arxiv.org/abs/1811.02508)和 [fast-bss-eval 文档](https://fast-bss-eval.readthedocs.io/en/latest/)。不默认使用允许长失真滤波器拟合的旧式 SDR；不同定义的榜单分数不直接混比。音乐分离的听感研究亦表明，不能以单一数值替代所有声部的听感评价：[Jaffe 与 Burgoyne](https://arxiv.org/abs/2507.06917)。该研究不是专门的主唱／伴唱验收研究。

### 避免虚高分

- 主唱、伴唱角色固定，关闭自动寻找最佳输出排列；交换两条轨不能仍算正确。
- 分开统计独唱、伴唱单独出现、同时唱的片段，核心报告包含同时唱的子集。
- 每首单列结果，报告中位数和最差 10% 窗口；不能让大量前奏、静音或简单独唱稀释困难片段。
- 窗口和参考活动判定参数在比较之前固定，只用参考轨判定活动。参考轨有声而输出静音必须计入失败，不能跳过；参考轨静音时单列输出泄漏电平，不算不稳定的 SDR 比值。
- 固定增益评分不拟合时间平移、DTW 或各输出独立归一化；SI-SDR 的标量投影只属于它自身的指标定义。
- 参考与目标包含一致的混响／声道定义。去混响属于另一项任务，不能把带混响参考当成无混响输出的正确答案。
- 比较同批歌曲的逐首差值；小幅平均分变化不直接宣称显著改善。已反复听过、调过的歌曲属于开发集。
- 公开预训练模型的训练数据可能不透明；若无法排除它见过测试材料，应如实标注，而不是声称完全未见的盲测。

## 只有混音时

目前 Lemon、晴天、群青、突然好想你只有原曲和模型估计，没有独立真实的 L/H/I。不能用模型输出给自己当参考，不报告它们的真实 SI-SDR、SI-SIR 或“分离纯度百分比”。

以下只能作工程检查／辅助诊断：

- 三轨重合误差：仅作数值诊断，不要求逐比特还原，也不证明分配正确。`主唱=全部人声、伴唱=0` 仍能完美还原。
- 能量比例：检查异常静音、爆音；伴唱变小不等于主唱泄漏变少，也可能是和声被一并删掉。
- 歌词识别率：主唱和伴唱可能唱相同歌词，不能据此区分声部。
- 声纹相似度：同一歌手可以同时录主唱和伴唱，不能靠身份相似度定义角色。

这四首采用同位置、共同增益的主唱与伴唱单独试听，再听“背景音乐＋伴唱”的实际演唱底轨。给两个方向的串音、目标完整度、伪影分别打分。

## 下一轮参考数据

[MoisesDB](https://github.com/moises-ai/moises-db) 的[声部分类](https://github.com/moises-ai/moises-db/blob/main/moisesdb/defaults.py)包含 lead male singer、lead female singer、background vocals 和 human choir。可挑选真正同时包含主唱和伴唱的多轨录音，并核对模糊的群唱角色后建立测试集。不能只使用已合并成一个 vocals.wav 的四轨版本。

先在这组真实分轨上测两个候选的客观差值，再与四首开发歌曲的试听偏好对应，校准可接受的串音与失真门槛。当前没有为新任务完成这项数据评测。
